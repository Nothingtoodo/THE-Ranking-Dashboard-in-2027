# THE 世界大學排名數據分析儀表板

國立臺灣科技大學 THE World University Rankings 2022–2027 互動分析。

製作人：永續發展與校務研究中心　林冠宇

## 操作方式

- 電腦：按 `↓`、`空白鍵` 或 `PageDown` 到下一頁，按 `↑` 或 `PageUp` 回上一頁，`Home`／`End` 跳到第一頁或最後一頁
- 手機：上下滑動，或點右下角的 ▲▼ 按鈕換頁；圖表可以左右滑動
- 右上角可以切換黑底／白底

## 資料來源

- Times Higher Education World University Rankings 2022–2027（官方公開排名資料）
- 方法學：THE World University Rankings 2027 methodology

## 發布到 GitHub Pages

1. 在 GitHub 建立新的 repository（例如 `ntust-the-dashboard`）
2. 上傳本資料夾內的 `index.html`、`.nojekyll`、`README.md`
3. 進入 repository 的 Settings → Pages，Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 Save
4. 約 1–2 分鐘後，網址為 `https://<帳號>.github.io/<repository 名稱>/`
